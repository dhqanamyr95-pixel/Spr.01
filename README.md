# ربات ارسال فیلم با عضویت اجباری (نسخه GitHub Actions)

این نسخه کاملاً روی گیت‌هاب اجرا می‌شود، رایگان و بدون کارت بانکی — دقیقاً با همان الگویی که در `coc-news-bot` استفاده کرده‌اید.

## چطور کار می‌کند؟
یک Workflow هر **۵ دقیقه** یک‌بار اجرا می‌شود. هر بار که اجرا می‌شود:
1. آخرین وضعیت ربات (`bot.db`، شامل کانال‌ها، ویدیوها، و آخرین پیام دریافتی) را از خود ریپو می‌خواند.
2. تا حدود ۴ دقیقه و نیم با روش long-polling به تلگرام گوش می‌دهد — یعنی در همین بازه، پاسخ‌دهی تقریباً آنی است، نه فقط یک چک ساده در لحظه‌ی شروع.
3. در پایان، `bot.db` به‌روزشده را دوباره در ریپو کامیت می‌کند تا اجرای بعدی از همانجا ادامه دهد.

**نتیجه برای کاربر نهایی:** بیشتر وقت‌ها پاسخ ربات تقریباً فوری است؛ فقط در بدترین حالت (وقتی پیام درست در فاصله‌ی بین دو اجرا برسد) ممکن است چند ثانیه تا حداکثر چند دقیقه طول بکشد.

## مراحل راه‌اندازی

### ۱. آپلود فایل‌ها در گیت‌هاب
تمام فایل‌های این پروژه را در ریپوی خودتان آپلود کنید، از جمله پوشه‌ی مخفی `.github/workflows/bot.yml` (روی گوشی موقع آپلود دقت کنید که این پوشه هم منتقل شود — اگر گیت‌هاب فایل‌های داخل `.github` را جدا نشان نداد، از حالت zip و git استفاده کنید).

فایل `.env` را **آپلود نکنید** — به‌جایش مقادیر را به‌صورت Secret در گیت‌هاب می‌گذاریم (مرحله بعد).

### ۲. تعریف Secrets در گیت‌هاب
1. در ریپو بروید به: **Settings → Secrets and variables → Actions**
2. روی **New repository secret** بزنید و این سه مورد را یکی‌یکی اضافه کنید:
   - نام: `BOT_TOKEN` — مقدار: توکن ربات از BotFather
   - نام: `BOT_USERNAME` — مقدار: `SOPERSPR_BOT`
   - نام: `ADMIN_IDS` — مقدار: `6719992896`

### ۳. فعال کردن Workflow
1. به تب **Actions** بروید.
2. اگر پیامی درباره‌ی فعال‌سازی Workflow دیدید، آن را تایید کنید.
3. روی workflow با نام **Run Telegram Bot** بزنید و یک‌بار دستی با دکمه **Run workflow** اجرا کنید تا مطمئن شوید درست کار می‌کند.

از این به بعد، خودش هر ۵ دقیقه اجرا می‌شود — نیازی به کار دستی نیست.

## استفاده از ربات
دقیقاً مثل نسخه‌های قبلی:
- `/addchannel @channel_username`, `/removechannel`, `/channels` برای مدیریت کانال‌های اجباری (فقط ادمین).
- ادمین یک ویدیو مستقیم برای ربات بفرستد → لینک اختصاصی می‌گیرد.
- کاربر روی لینک بزند → اگر عضو کانال‌ها نبود، دکمه‌ی عضویت + «عضو شدم، بررسی کن» می‌بیند → بعد از تایید، فیلم فقط برایش ارسال می‌شود.
- دکمه‌ی «📤 آپلود ویدیو» برای کاربران عادی → فیلم برای ادمین با دکمه‌های تایید/رد ارسال می‌شود → بعد از تایید وارد کتابخانه می‌شود.

## نکات مهم
- ریپو باید **Public** باشد تا Actions نامحدود و رایگان بماند (دقیقاً مثل ربات اخبار کلش‌تان).
- هر بار Workflow اجرا می‌شود، یک کامیت جدید (`chore: update bot state`) در تاریخچه‌ی ریپو می‌بینید — طبیعی است، دقیقاً مثل `posted.json` در ربات قبلی.
- هیچ‌وقت توکن را در کد یا `.env` داخل گیت‌هاب قرار ندهید؛ فقط در Secrets.
- اگر روزی خواستید سرعت پاسخ را کاملاً آنی و بدون هیچ تاخیری کنید، گزینه‌ی نسخه‌ی Webhook روی PythonAnywhere هم آماده است (که قبلاً برایتان فرستادم) — آن نسخه اصلاً منتظر زمان‌بندی نمی‌ماند.
